# Changelog

## 0.1.0 — Initial release

- Added the default Facebook, Infosys Springboard and Zoom sender rules.
- Added natural-language command parsing with an optional OpenAI Responses API parser and local fallback.
- Added Google OAuth and Gmail API search / metadata retrieval.
- Added exact sender validation, date filters and a preview-size limit.
- Added expiring, single-use deletion previews and explicit confirmation.
- Added per-message sender revalidation and Trash-only actions.
- Added CLI, FastAPI endpoints, SQLite persistence, tests and GitHub Actions CI.
